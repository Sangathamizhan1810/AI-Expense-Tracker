### Task 2: Database Schema Definition
**Type**: implementation  
**Files**: `database/schema.sql`

Define the SQL DDL for all four tables:

```sql
-- users table
CREATE TABLE IF NOT EXISTS users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL,
    email TEXT NOT NULL UNIQUE,
    password_hash TEXT NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- categories table
CREATE TABLE IF NOT EXISTS categories (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT NOT NULL UNIQUE
);

-- expenses table
CREATE TABLE IF NOT EXISTS expenses (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    category_id INTEGER NOT NULL,
    amount REAL NOT NULL CHECK(amount > 0),
    expense_date DATE NOT NULL,
    note TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (user_id) REFERENCES users(id),
    FOREIGN KEY (category_id) REFERENCES categories(id)
);

-- budgets table
CREATE TABLE IF NOT EXISTS budgets (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    user_id INTEGER NOT NULL,
    category_id INTEGER NOT NULL,
    month TEXT NOT NULL,  -- format: YYYY-MM
    limit_amount REAL NOT NULL CHECK(limit_amount > 0),
    UNIQUE(user_id, category_id, month),
    FOREIGN KEY (user_id) REFERENCES users(id),
    FOREIGN KEY (category_id) REFERENCES categories(id)
);
```

**Verification**: Schema loads without errors when the app initializes.

### Task 3: Category Seeder & Database Initialization
**Type**: implementation  
**Files**: `database/seed.sql`, `utils/db.py`, `app.py`

**seed.sql**: INSERT the 8 categories (Food, Travel, Shopping, Bills, Entertainment, Health, Education, Other) using `INSERT OR IGNORE`.

**utils/db.py**: Database helper module:
- `get_db()` — returns a `sqlite3.Connection` with `row_factory = sqlite3.Row`
- `close_db(e=None)` — closes connection stored on Flask `g`
- `init_db()` — reads `schema.sql` and `seed.sql`, executes them
- `init_app(app)` — registers `close_db` teardown and CLI command `flask init-db`

**app.py**: Create the Flask application factory pattern:
- `create_app()` function
- Register database teardown
- Ensure `instance/` directory exists
- Auto-initialize DB on first run if `expense_tracker.db` doesn't exist

**Verification**: Running `flask init-db` creates `instance/expense_tracker.db` with all 4 tables and 8 seeded categories.
