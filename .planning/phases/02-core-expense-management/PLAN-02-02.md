# Plan 02-02: Expense List, Dynamic Filtering, Sorting & CSV Export

**Phase**: 2 — Core Expense Management & Export  
**Plan**: 02-02  
**Requirements**: EXP-02, EXP-05, EXP-06  
**Estimated tasks**: 4

## Objective

Implement the expense management table view, complete with dynamic multi-criteria filtering (date range and category), sorting by date or amount, quick summary metrics (total spend of filtered set), and a robust CSV export endpoint.

## Context

- Users need to review their historical expenses clearly in a structured, sortable table.
- Filtering allows narrowing down expenses by specific timeframe (from date to date) and by category.
- Summary bar must dynamically display the total filtered amount in Indian Rupees (`₹`) and count of entries.
- Export functionality must generate RFC 4180 compliant CSV files with appropriate MIME headers (`text/csv`), reflecting either the filtered dataset or all user records.
- Complete data isolation must be maintained: exported CSV and table rows must never contain another user's transactions.

## Tasks

### Task 1: Filtered Querying & Pagination Helpers
**Type**: implementation  
**Files**: `utils/expense_helpers.py`

Implement query helper functions supporting dynamic filtering and sorting:
- `get_expenses(user_id, category_id=None, start_date=None, end_date=None, sort_by='date', sort_order='desc', limit=None, offset=None)`:
  - Dynamically builds parameterized SQL query (`WHERE user_id = ?`) with optional `AND category_id = ?`, `AND expense_date >= ?`, `AND expense_date <= ?`.
  - Whitelist validates sorting column (`expense_date`, `amount`) and direction (`ASC`, `DESC`) to prevent SQL injection.
  - Joins `categories` table to include `category_name`.
  - Returns list of expense rows.
- `get_expenses_summary(user_id, category_id=None, start_date=None, end_date=None)`:
  - Computes `COUNT(*)` and `COALESCE(SUM(amount), 0)` for the current filter parameters in a single efficient query.

**Verification**: Helper returns correct counts, sums, and sorted results under various filter combinations.

### Task 3: CSV Export Endpoint
**Type**: implementation  
**Files**: `expenses.py`

Route `GET /expenses/export`:
- Extracts filter arguments (`category`, `start_date`, `end_date`, `sort`, `order`).
- Queries filtered expenses for the logged-in user using `get_expenses()`.
- Uses Python's built-in `csv` module and `io.StringIO` to generate CSV text.
- Columns: `Expense ID`, `Date`, `Category`, `Amount (INR)`, `Notes`, `Logged At`.
- Returns Flask `Response` with:
  - `Content-Type: text/csv; charset=utf-8`
  - `Content-Disposition: attachment; filename=expenses_YYYY-MM-DD.csv`
- Security check: ensure only logged-in user's data is exported.

**Verification**: Calling `/expenses/export` returns a downloadable CSV file containing only the user's records with valid headers and data formatting.

1. Expense list displays all logged transactions with category badges and formatted amounts.
