# Plan 03-01: Labelled Training Dataset, TF-IDF + Logistic Regression Model & Inference Pipeline

**Phase**: 3 — NLP & Machine Learning Categorization  
**Plan**: 03-01  
**Requirements**: NLP-03, NLP-04, NLP-05 (partial)  
**Estimated tasks**: 4

## Objective

Create a curated 300+ item training dataset across 8 expense categories, build an offline training pipeline (`train_model.py`) using scikit-learn (`TfidfVectorizer` + `LogisticRegression`), achieve $\ge 85\%$ test classification accuracy, serialize the trained pipeline as `model.joblib`, and implement a cached inference helper with confidence probability scoring and threshold fallback.

## Context

- Strict offline constraint: The model must run entirely local on the CPU with zero internet connection, zero API cost, and sub-50ms inference latency.
- Categories must exactly match the 8 seeded categories in `categories` table: `Food`, `Travel`, `Shopping`, `Bills`, `Entertainment`, `Health`, `Education`, `Other`.
- Training pipeline will be evaluated on a held-out test split (20%) using stratified sampling.
- Model must output both the predicted category and a probability confidence score (`0.00` to `1.00`).
- If confidence score $< 0.50$, inference marks `is_low_confidence = True` and defaults to `"Other"` while retaining the best candidate guess for user review.

## Tasks

### Task 1: Curated Training Dataset
**Type**: data  
**Files**: `data/expenses_dataset.csv`

Create a clean CSV dataset of 320+ representative everyday expense expressions (at least 40 diverse examples per category):
- `text`: natural description phrase (e.g., "swiggy dinner chicken biryani", "metro smart card recharge", "amazon prime annual subscription", "apollo pharmacy medicines", "electricity bill tneb", "udemy web development course", "myntra running shoes")
- `category`: one of `Food`, `Travel`, `Shopping`, `Bills`, `Entertainment`, `Health`, `Education`, `Other`

Ensure rich vocabulary representing Indian consumer spend (e.g. Swiggy, Zomato, Uber, Ola, IRCTC, D-Mart, Blinkit, Zepto, BESCOM, Airtel, Jio, Lenskart).

**Verification**: CSV parses cleanly with 320+ rows, 8 balanced categories, and no null values.

---

### Task 2: Machine Learning Training Pipeline
**Type**: ML / script  
**Files**: `train_model.py`

Write a standalone reproducible training script:
1. Loads `data/expenses_dataset.csv`.
2. Preprocesses text (lowercase, strip extra whitespaces/punctuation).
3. Splits data into train (80%) and test (20%) with `stratify=y, random_state=42`.
4. Builds a scikit-learn `Pipeline`:
   - `TfidfVectorizer(ngram_range=(1, 2), sublinear_tf=True, min_df=1)`
   - `LogisticRegression(C=1.5, max_iter=1000, random_state=42)`
5. Trains the pipeline on the training split.
6. Evaluates test set accuracy and prints classification report (precision, recall, F1 per category).
7. Asserts test accuracy $\ge 85\%$.
8. Saves the serialized pipeline to `model.joblib` using `joblib.dump()`.

**Verification**: Running `python train_model.py` executes in under 5 seconds, prints test accuracy $\ge 85\%$, and outputs `model.joblib`.

---

### Task 3: Cached Model Inference Helper
**Type**: implementation  
**Files**: `utils/nlp_classifier.py`

Implement the inference module:
- `load_model()`: Cached singleton loader for `model.joblib`. If the model file is not found, automatically runs training or raises clean descriptive error.
- `predict_category(text, confidence_threshold=0.5)`:
  - Takes raw description text (e.g. "zomato cheese pizza").
  - Computes class probabilities via `pipeline.predict_proba([cleaned_text])[0]`.
  - Determines top category and its confidence score (`round(max_prob, 2)`).
  - If `confidence < confidence_threshold`:
    - Returns `{'category': 'Other', 'confidence': confidence, 'is_low_confidence': True, 'raw_prediction': top_cat}`
  - Else:
    - Returns `{'category': top_cat, 'confidence': confidence, 'is_low_confidence': False, 'raw_prediction': top_cat}`
- `get_category_id_by_name(category_name)`: Helper to map predicted category string to SQLite database `category_id`.

**Verification**: Inference function returns expected categories and probabilities for sample test phrases ("swiggy 300" -> Food, "uber ride" -> Travel, "netflix" -> Entertainment).
