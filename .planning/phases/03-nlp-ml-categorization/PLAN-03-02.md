# Plan 03-02: NLP Sentence Parser, Regex Engine & AI Quick-Add Interactive Flow

**Phase**: 3 — NLP & Machine Learning Categorization  
**Plan**: 03-02  
**Requirements**: NLP-01, NLP-02, NLP-05  
**Estimated tasks**: 4

## Objective

Build the NLP sentence parsing engine (extracting numeric amount via regular expressions and isolating descriptive text for ML inference), create the AI Quick-Add user interface with real-time prediction feedback and confidence badges, allow manual user overrides, and seamlessly record expenses from natural language inputs.

## Context

- Users want to type natural expressions like "Swiggy 250", "metro recharge 50", "₹1200 electricity bill", "paid 45 for tea", "petrol 500 rs" without manually clicking through separate fields.
- Regex engine must handle various currency symbols and patterns:
  - Number at end: `"Swiggy 250"`, `"bus ticket 30"`
  - Currency prefix: `"₹500 petrol"`, `"rs 350 grocery"`, `"INR 1200"`
  - Currency suffix: `"auto 40 rs"`, `"coffee 120 rupees"`
  - Mid-sentence: `"paid 45.50 for breakfast"`
- After extracting the amount, the leftover text must be stripped of numbers and currency symbols before feeding into the ML classifier.
- Interface must display the parsed amount, predicted category, confidence pill badge (e.g. `95% confident`), and allow the user to adjust before saving.

## Tasks

### Task 1: Regex Amount Extraction & Text Cleaning Engine
**Type**: implementation  
**Files**: `utils/nlp_parser.py`

Implement regex parser functions:
- `extract_amount(text)`:
  - Detects patterns: `(?:₹|rs\.?|inr)?\s*(\d+(?:\.\d{1,2})?)\s*(?:rs\.?|rupees|inr)?`
  - Returns tuple: `(float_amount_or_none, cleaned_description)`
  - Example:
    - `"Swiggy 250"` -> `(250.0, "Swiggy")`
    - `"paid ₹150 for auto to office"` -> `(150.0, "paid for auto to office")`
    - `"movie ticket 350 rs"` -> `(350.0, "movie ticket")`
    - `"groceries"` -> `(None, "groceries")`
- `parse_expense_sentence(sentence)`:
  - Runs `extract_amount(sentence)`
  - Feeds remaining text into `predict_category(cleaned_description)`
  - Looks up corresponding `category_id` in SQLite
  - Returns structured dictionary:
    ```python
    {
        'raw_input': sentence,
        'amount': amount,  # float or None
        'description': description,  # string
        'category_name': category_name,  # string
        'category_id': category_id,  # int
        'confidence': confidence,  # float (0.0 to 1.0)
        'is_low_confidence': is_low_confidence,  # bool
        'expense_date': date.today().isoformat()
    }
    ```

**Verification**: Test suite verifies extraction across at least 15 distinct sentence formats.

### Task 2: AI Parse & Quick-Add API Endpoints
**Type**: implementation  
**Files**: `expenses.py`

Add routes to `expenses_bp`:
- `POST /expenses/ai-parse`:
  - Accepts JSON or form data `{'sentence': '...'}`
  - Calls `parse_expense_sentence(sentence)`
  - Returns JSON response for dynamic interactive preview.
- `POST /expenses/ai-quick-add`:
  - Parses sentence; if amount is found, creates expense directly.
  - If amount is missing or user requests confirmation, redirects to pre-filled `/expenses/add` form.
  - Flashes success message highlighting parsed amount and predicted category with confidence.

**Verification**: Calling `/expenses/ai-parse` with `"Swiggy 300"` returns HTTP 200 with JSON payload containing amount 300.0 and Food category.
