# Plan 04-01: Monthly Category Budgets, Real-Time Spend Tracking & Alert Engine

**Phase**: 4 — Budget Management & Alert Engine  
**Plan**: 04-01

**Estimated tasks**: 4

## Objective

Build the monthly category budget system and real-time alert engine: allow users to configure monthly spending limits for any category, automatically aggregate current month expenditures per category, calculate utilization percentages, trigger visual warning badges at $\ge 80\%$ utilization, and fire critical overspending alerts when spend reaches or exceeds $100\%$.

## Context

- `budgets` table schema has `UNIQUE(user_id, category_id, month)`.
- Months are formatted as `YYYY-MM` (e.g., `2026-10`), defaulting to the current calendar month.
- An expense counts towards a budget if its `expense_date` falls within the same `YYYY-MM`.
- Status thresholds:
  - **Normal** (`< 80%`): Progress bar in primary accent / green, calm status.
  - **Warning** (`80% – 99%`): Warning amber badge and glow alert indicating spending is approaching the limit.
  - **Exceeded** (`>= 100%`): Danger red alert indicating overspending with overage amount displayed.
  - **Unset**: Category has no budget set; allows 1-click limit configuration.
- Users can switch months to review past budget performance or plan upcoming months.

## Tasks

### Task 1: Budget Data Helpers & Alert Calculation Engine
**Type**: implementation  
**Files**: `utils/budget_helpers.py`

Implement helper functions ensuring complete user data isolation (`WHERE user_id = ?`):
- `get_budgets_for_month(user_id, month=None)`:
  - Defaults `month` to current `YYYY-MM` if not provided.
  - Fetches all 8 categories.
  - Computes total expenses for each category in that month:
    `SELECT category_id, COALESCE(SUM(amount), 0.0) FROM expenses WHERE user_id = ? AND strftime('%Y-%m', expense_date) = ? GROUP BY category_id`.
  - Joins existing budget limits from `budgets` table.
  - Calculates per category:
    - `limit_amount`: float or None
    - `spent_amount`: float
    - `remaining_amount`: `limit_amount - spent_amount` if budget exists else None
    - `percentage`: `round((spent_amount / limit_amount) * 100, 1)` if budget exists else 0
    - `status`: `'exceeded'` (>= 100%), `'warning'` (>= 80%), `'normal'` (< 80%), or `'unset'`
  - Computes overall monthly totals: `total_budget`, `total_spent`, `total_remaining`, `overall_percentage`.
- `set_or_update_budget(user_id, category_id, month, limit_amount)`:
  - Validates positive limit (`limit_amount > 0`).
  - Upserts into `budgets` table using `INSERT ... ON CONFLICT(user_id, category_id, month) DO UPDATE`.
- `delete_budget(budget_id, user_id)`:
  - Deletes budget record belonging to the user.
- `get_active_alerts(user_id, month=None)`:
  - Returns list of categories currently in `'warning'` or `'exceeded'` state for notification banners.

**Verification**: Helper accurately computes sums, percentages, warning flags, and overspending statuses.

### Task 2: Budgets Blueprint & Controller Endpoints
**Type**: implementation  
**Files**: `budgets.py`, `app.py`

Create `budgets_bp = Blueprint('budgets', __name__, url_prefix='/budgets')`:
- `@budgets_bp.before_request`: Enforce `@login_required`.
- `GET /budgets`:
  - Reads `month` query parameter (defaults to current `YYYY-MM`).
  - Calls `get_budgets_for_month(user_id, month)`.
  - Renders `templates/budgets/index.html`.
- `POST /budgets/set`:
  - Accepts `category_id`, `month`, `limit_amount`.
  - Calls `set_or_update_budget(...)`.
  - Flashes success message ("Budget for {category} set to ₹{limit_amount} for {month}!").
  - Redirects back to `/budgets?month={month}`.
- `POST /budgets/<int:id>/delete`:
  - Deletes budget record with user ownership verification.
  - Flashes confirmation and redirects.

Register `budgets_bp` in `app.py`.

**Verification**: Endpoints respond correctly, validate inputs, and update budget state per user.

### Task 3: Interactive Budget Dashboard Template & Alert Banners
**Type**: frontend + UI  
**Files**: `templates/budgets/index.html`, `static/css/style.css`

Design the budget management view:
1. **Header & Month Selector**:

2. **Active Alert Banners**:
   - Prominent alert container rendered if any categories are at $\ge 80\%$ or $\ge 100\%$:

3. **Monthly Health KPI Grid**:
   - Total Monthly Budget (₹).
   - Total Monthly Spent (₹).
   - Remaining Safe Spend (₹).
   - Overall Budget Utilization Progress Bar.
4. **Category Budget Cards Grid**:
   - 8 cards (one for each category).
   - Category name & icon badge.
   - Status badge:
     - Green pill: `Normal (45%)`
     - Amber pill: `⚠️ Warning (85%)`
     - Red pill: `🚨 Exceeded (115%)`
     - Gray pill: `No Budget Set`

     - Green `< 80%`
     - Amber `80% – 99%`

5. **Set / Edit Budget Modal**:
   - Modal dialog allowing user to set or update budget with currency prefix (`₹`).

**Verification**: Page displays accurate progress bars, colors change dynamically at 80% and 100%, and modals save without page breakage.
