# Plan 05-01: Interactive Visual Analytics Dashboard

**Phase**: 5 — Interactive Visual Analytics Dashboard  
**Plan**: 05-01  
**Requirements**: DASH-01, DASH-02, DASH-03, DASH-04  
**Estimated tasks**: 4

## Objective

Build a comprehensive, interactive financial dashboard featuring high-level financial KPI cards and three Chart.js visual analytics charts (Category Breakdown Donut, Spending Trend Line, and Budget vs. Actual Bar Chart) with calendar month filtering and complete user data isolation.

## Context

- Existing components:
  - `expenses` table contains date, amount, description, category_id, and user_id.
  - `budgets` table contains user_id, category_id, month (`YYYY-MM`), and amount.
  - `categories` table contains standard names, icons, and hex color codes.
  - App navigation currently points `/dashboard` to `expenses.index`.
- Requirements to fulfill:
  - **DASH-01**: Financial KPI summary cards (Total Monthly Spend, Active Budgets, Remaining Spend Capacity, Top Spending Category).
  - **DASH-02**: Interactive Chart.js Donut/Pie chart displaying category-wise spending distribution.
  - **DASH-03**: Spending trend Line chart showing expense trajectory over time.
  - **DASH-04**: Budget vs. Actual Bar chart comparing current spend with allocated limits.
- Design Aesthetics:
  - Dark-theme glassmorphic styling matching design tokens in `static/css/style.css`.
  - Chart.js canvas elements configured with dark grid lines, glowing borders, and custom currency tooltips.
  - Responsive layout that stacks cleanly on mobile and displays side-by-side on desktop.

## Tasks

### Task 1: Analytics Data Aggregation Helpers
**Type**: implementation  
**Files**: `utils/analytics_helpers.py`

Create analytics aggregation module with strict user isolation (`WHERE user_id = ?`):
- `get_monthly_kpis(user_id, month=None)`:
  - Defaults to current calendar month (`YYYY-MM`) if not provided.
  - Computes:
    - `total_spent`: Total sum of expenses for the given month.
    - `total_budget`: Sum of allocated budgets for the given month.
    - `budget_remaining`: `total_budget - total_spent` (or 0 if no budgets).
    - `budget_utilization`: Percentage of overall budget spent.
    - `top_category`: Category with highest expenditure in the month (`name`, `amount`, `percentage`, `icon`, `color`), or `None` if zero expenses.
    - `expense_count`: Total number of transactions in the month.
- `get_category_distribution(user_id, month=None)`:
  - Aggregate sums per category for the specified month.
  - Returns structured dataset: `labels`, `amounts`, `percentages`, `colors`, `icons`.
- `get_spending_trends(user_id, months_count=6, reference_month=None)`:
  - Computes total expenses for the last `N` consecutive calendar months up to `reference_month`.
  - Returns `months` (formatted as e.g. `['May', 'Jun', 'Jul', 'Aug', 'Sep', 'Oct']`), `keys` (`YYYY-MM`), and `amounts`.
- `get_budget_vs_actual(user_id, month=None)`:
  - For all categories that either have a budget set or have recorded spending in the month:
  - Returns `categories`, `budget_amounts`, `actual_amounts`, and `percentages`.

**Verification**: Helper accurately computes correct figures, handles zero-expense months gracefully, and isolates user records.

### Task 2: Dashboard Blueprint & Analytics API Endpoints
**Type**: implementation  
**Files**: `dashboard.py`, `app.py`, `templates/base.html`

Create `dashboard_bp = Blueprint('dashboard', __name__, url_prefix='/dashboard')`:
- `GET /dashboard`:
  - Protected with `@login_required`.
  - Accepts optional query param `?month=YYYY-MM` (defaults to current month).
  - Fetches KPIs, category distribution, trend history, and budget vs actual data.
  - Renders `templates/dashboard/index.html` with data pre-injected as JSON for instant hydration.
- `GET /dashboard/api/analytics`:
  - Returns JSON payload containing `{kpis, category_distribution, spending_trends, budget_vs_actual}`.
  - Enables seamless client-side month switching without full page refresh.
- Update `app.py`:
  - Register `dashboard_bp`.
  - Update root route (`/`): logged-in users redirect to `dashboard.index` as the primary home screen.
- Update `templates/base.html`:
  - Add "Dashboard" link in the navigation bar before "Expenses" and "Budgets".

**Verification**: Endpoints return HTTP 200 with valid analytics data and enforce authentication.

### Task 3: Interactive Dashboard UI with Chart.js
**Type**: implementation  
**Files**: `templates/dashboard/index.html`, `static/css/style.css`, `static/js/dashboard.js`

Build the dashboard template and interactive client charts:
- **Header & Filter Toolbar**:
  - Greeting / Title with current active month indicator.
  - Month selector (`<input type="month">`) with previous/next month navigation buttons.
  - Quick "+ Add Expense" CTA.
- **KPI Summary Cards (DASH-01)**:
  - Card 1: **Total Monthly Spend** (rupee formatted, transaction count badge).
  - Card 2: **Remaining Spend Capacity** (green/amber/red depending on health).
  - Card 3: **Active Budgets & Utilization** (overall % with mini progress indicator).
  - Card 4: **Top Spending Category** (category badge, amount, and % of monthly total).
- **Chart 1: Category Breakdown Donut Chart (DASH-02)**:
  - Donut chart with smooth hover cutouts.
  - Colors matched to database category color codes.
  - Custom HTML legend or interactive Chart.js tooltips with ₹ and %.
  - Center label displaying total spend.
- **Chart 2: Monthly Spending Trend Line Chart (DASH-03)**:
  - 6-Month trajectory line chart with curved lines (`tension: 0.35`).
  - Gradient accent area fill under curve.
  - Tooltips showing monthly total and month-over-month direction.
- **Chart 3: Budget vs. Actual Bar Chart (DASH-04)**:
  - Side-by-side grouped horizontal or vertical bar chart comparing "Budget Limit" vs "Actual Spend".
  - Alert highlighting for categories that exceed 100% of budget.
- **Empty State**:
  - Graceful placeholder card when no expenses are logged for the month, prompting the user to use AI Quick-Add.

**Verification**: Charts render smoothly, responsive on mobile/desktop, no console errors, and dynamic month switcher updates all charts.
