# Plan 06-01: Spending Insights Engine & Month-over-Month Analytics

**Phase**: 6 — Spending Insights Engine, UAT & Documentation  
**Plan**: 06-01  
**Requirements**: INS-01, INS-02, INS-03, INS-04  
**Estimated tasks**: 3

## Objective

Build a deterministic, rule-based spending insights engine that compares current month spending with the previous month, produces up to three dynamic plain-language observations grounded strictly in mathematical calculation, generates personalized actionable saving tips based on budget utilization, and provides graceful fallback messaging for new accounts.

## Context

- The system operates without external paid LLM APIs; observations and savings tips are generated through pure deterministic logic in Python to guarantee 100% calculation accuracy and zero context drift.
- Month-over-month comparison requires evaluating both `month` (e.g., `2026-10`) and `prev_month` (`2026-09`).
- Requirements:
  - **INS-01**: Analyze current vs. previous month spending per category and in total.
  - **INS-02**: Output up to 3 plain-language dynamic observations (e.g., "Food spending is 40% higher than last month").
  - **INS-03**: Output actionable savings tips based on budget utilization and high-spend categories.
  - **INS-04**: Display graceful fallback state ("Not enough data yet") for accounts without prior-month history.

## Tasks

### Task 1: Rule-Based Insights Engine Helper
**Type**: implementation  
**Files**: `utils/insights_helpers.py`

Implement `utils/insights_helpers.py` strictly isolated by `user_id`:
- `get_month_over_month_summary(user_id, month=None)`:
  - Identifies target month `M` and prior month `M-1`.
  - Queries total spending and category spending for both months.
  - Computes:
    - Overall delta amount (`current_total - prev_total`) and percentage change.
    - Per-category deltas: amount change, percentage change, and status (`increased`, `decreased`, `new`, `zero`).
- `generate_spending_insights(user_id, month=None)`:
  - Generates structured response:
    - `has_enough_data`: bool (True if previous month has expenses, False otherwise).
    - `observations`: list of observation objects `{'type': 'increase'|'decrease'|'milestone'|'summary', 'icon': str, 'text': str, 'category': str}` (up to 3).
    - `savings_tips`: list of actionable recommendation objects `{'icon': str, 'title': str, 'text': str, 'priority': 'high'|'medium'|'tip'}`.
    - `month_label`: e.g. "October 2026".
    - `prev_month_label`: e.g. "September 2026".
  - Rule logic:
    - **Total Spend Trend**: e.g., "Total spending is down by 14.5% compared to September 2026 (₹4,200 vs ₹4,910)."
    - **Significant Category Spike**: Finds category with largest percentage or absolute increase (e.g., "Food spending increased by 38.2% (₹1,350 vs ₹977) this month.").
    - **Category Savings Win**: Finds category with largest reduction (e.g., "Great job! Shopping expenses dropped by 25.0% this month.").
    - **Budget-Aware Savings Tips**:
      - If category is Exceeded (>100%): "Critical: Shopping budget exceeded by ₹450. Pause discretionary shopping until next month."
      - If category is in Warning (80%-99%): "Caution: Travel has reached 88% of your limit with 10 days remaining."
      - Discretionary spend tip: If top category is Food or Entertainment, suggests cooking at home or streaming alternatives.
    - **New User Fallback** (INS-04): If `prev_total == 0`:
      - Shows "First Month Tracking: You have logged ₹X across Y categories so far. Full month-over-month insights will activate next month!"

**Verification**: Helper passes comprehensive unit tests with zero division errors, correct percentage rounding, and accurate fallback triggers.
