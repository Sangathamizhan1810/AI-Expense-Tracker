## Tasks

### Task 1: Comprehensive 13-Case UAT Test Suite
**Type**: test  
**Files**: `tests/test_phase6_uat.py`

Implement test cases matching the mini-project specification:
- `test_tc01_user_registration_valid`: Valid user sign up, password hashing verification.
- `test_tc02_user_registration_invalid`: Duplicate email and short password rejection.
- `test_tc03_user_login_success`: Valid login and session authentication.
- `test_tc04_user_login_failure`: Invalid password rejection and error message.
- `test_tc05_manual_expense_creation`: Expense entry with amount, category, date, and note.
- `test_tc06_expense_validation`: Rejection of negative amounts, invalid categories, and bad dates.
- `test_tc07_expense_filtering_and_csv_export`: Filter by category and date range + RFC 4180 CSV export.
- `test_tc08_ai_expense_nlp_parsing`: Correct extraction of rupee amounts and category prediction.
- `test_tc09_ai_classifier_fallback`: Fallback to "Other" or low confidence handling on unknown text.
- `test_tc10_monthly_budget_allocation`: Budget allocation and atomic upsert on conflict.
- `test_tc11_budget_alert_thresholds`: 80% warning badge and 100% critical overspending alert triggers.
- `test_tc12_analytics_dashboard_metrics`: KPI cards, donut distribution, 6-month trajectory, and bar chart comparison.
- `test_tc13_spending_insights_engine`: Month-over-month calculation, savings recommendations, and new account fallback.

**Verification**: Run all 13 test cases and verify 100% pass rate.
