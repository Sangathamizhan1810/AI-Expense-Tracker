**Phase**: 8 — Dual-Theme Architecture  
**Plan**: 08-01

---

## Objective

Establish an Architectural Daylight (Light Mode) theme alongside the existing Dark Terminal, equipped with a topbar/navbar geometric SVG toggle switch, zero-FOUC instantaneous persistence, and reactive Chart.js canvas synchronization—while preserving strict Anti-Slop principles (<3% chroma, 1px crisp hairlines, tabular numerals, zero emojis).

---

## Design Contract (Daylight Terminal)

1. **Strict Neutral Palette**:
   - Canvas Ground: `#f8fafc` (Slate 50)
   - Surface / Cards: `#ffffff` (Pure white) with 1px hairline border `#e2e8f0` (Slate 200)
   - Sunken / Recessed: `#f1f5f9` (Slate 100) for inputs, observations, and NLP HUD
   - Raised Controls: `#e2e8f0` (Slate 200)
   - Primary Text: `#090d16` (Deep ink black, high contrast)
   - Secondary Text: `#475569` (Slate 600)
   - Muted Text: `#64748b` (Slate 500)
   - Primary CTA: Inverted deep ink `#090d16` background with `#ffffff` text (hover `#1e293b`)
2. **Chart.js Synchronization**:
   - Gridlines: `#e2e8f0`
   - Trend Line: `#0f172a` (bold ink) with `#0f172a` point fills and `#ffffff` borders
   - Budget Bar Limit: `#e2e8f0` with border `#cbd5e1`
   - Tooltips: Deep obsidian `#090d16` container with white `#f8fafc` text
3. **Zero-FOUC Guarantee**:
   - Head-injected blocking theme resolver before paint, preventing theme flashing on multi-page navigation.
4. **Placement & Control**:
   - Authenticated: Desktop topbar right (adjacent to "+ New Record") & mobile topbar right.
   - Public / Auth: Navbar right menu.
   - Control: High-precision geometric SVG Sun/Moon toggle with smooth 180° rotation and accessibility labels.

## Tasks

### Task 1: Light Theme CSS Custom Properties & Component Overrides
- File: `static/css/style.css`
- Add `[data-theme="light"]` token overrides for all ground, surface, border, and text variables.
- Adapt component classes that previously used hardcoded dark values (`.btn--primary`, `.navbar`, `.brand-icon`, `.brand-glyph`, modal backdrops, `.amount-cell`, custom select arrow SVG).
- Add CSS styling for the theme toggle button (`.theme-toggle-btn`) with smooth transition effects.

### Task 2: Zero-FOUC Head Engine & Topbar/Navbar Toggle Switch UI
- File: `templates/base.html`
- In `<head>`, insert synchronous pre-render theme resolver script.
- In authenticated `.app-topbar-right`, add the desktop theme toggle button (`#theme-toggle-btn`).
- In mobile topbar, ensure accessibility on mobile viewport.
- In public navigation `.nav-menu`, add public theme toggle button (`#public-theme-toggle-btn`).

### Task 3: Global Theme Controller & Chart.js Reactive Re-coloring
- Files: `static/js/main.js`, `static/js/dashboard.js`
- `static/js/main.js`: Implement `initThemeToggle()` to handle click events, toggle `data-theme`, store preference in `localStorage`, update ARIA labels, and dispatch `themechange` CustomEvent.
- `static/js/dashboard.js`: Listen for `themechange` event to update chart options (grid colors, line strokes, budget limit fills) and call `chart.update()`.

### Task 4: Automated Test Verification & Multi-Screen Audit
- Run existing automated test suite (`pytest`) to verify no backend or template syntax regressions.
- Verify both Dark (default) and Light mode across:
  - Landing page (`/`)
  - Login & Register (`/login`, `/register`)
  - Dashboard (`/dashboard`)
  - Expense Ledger (`/expenses`)
  - Budget Tracker (`/budgets`)
- Verify zero FOUC on page transitions.
