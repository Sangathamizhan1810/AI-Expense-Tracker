## Objective

Recreate the visual design provided in the reference image across the AI Expense Tracker application:
1. Deep obsidian canvas (`#090a0d`) with a subtle dot-matrix background pattern.
2. High-voltage chartreuse / neon-lime primary accent (`#d4ff59` / `#e2fd52`) for high-impact metric cards, active states, and key CTAs.
3. Compact left-rail icon navigation with active neon squircle buttons and bottom utility links.
4. Top header bar featuring breadcrumbs, date range navigator pill (`< Today, Sep 25 >`), notification indicator, and user profile capsule.
5. Large display greeting (`Hello [User]`) with prominent neon action button.
6. Three top hero KPI cards in full neon lime with inverted dark typography and micro-pills.
7. Asymmetric 2-row widget layout:
   - Row 1: Semicircle Budget Gauge (Firewall Activity), Monthly Histogram with canvas gradient fade (Alert Volume), and Dual-curve Spline Trends (Breakdown).
   - Row 2: Daily Spend Velocity Equalizer (Operations) and Recent Transactions / Anomaly Queue Data Table.
8. Retain 100% functionality and ensure all 56+ existing automated test cases pass without regressions.

---

## Design Contract

### 1. Palette & Surface Hierarchy
- **Canvas Ground**: `#090a0d` with 20px dot grid: `radial-gradient(rgba(255, 255, 255, 0.08) 1px, transparent 1px)`
- **Surface / Card Background**: `#121316` (elevated `#16181d`) with 1px border `rgba(255, 255, 255, 0.06)`
- **Hero Surface (High-Voltage Lime)**: `#d4ff59` (hover `#e2fd52`) with high-contrast `#090a0d` dark ink text
- **Text Primary**: `#ffffff` (crisp white, high contrast)
- **Text Secondary / Muted**: `#8b92a2` (cool silver) and `#5a6272`
- **Pill Badges**: `#090a0d` on lime cards, and semi-transparent badges (`rgba(212, 255, 89, 0.15)`) on dark cards

### 2. Left Rail Navigation (Fixed ~72px)
- Fixed vertical sidebar with:
  - Brand icon at top
  - Squircle active button with neon-lime background (`#d4ff59`) and dark active icon
  - Minimal stroke icons for secondary modules (Expenses, Budgets, Analytics)
  - Bottom actions: Settings, Logout

### 3. Topbar & Header Cluster
- Left: Breadcrumb / Page Title (`Dashboard`)
- Right: Capsule date switcher (`< Today, Sep 25 >`), Notification bell with indicator dot, User avatar capsule (`avatar + Name + @handle`)
- Hero Row: `Hello [User]` display headline (`32px`, bold) + `+ Add Expense` neon button

### 4. Interactive Charts & Widgets
- **Semi-Circle Gauge**: Budget consumption arc (0% to 100%) with needle indicator and floating percentage chip.
- **Gradient Bar Chart**: Monthly expense columns with bottom-dark to top-lime vertical gradient and floating peak badge (`+80%`).
- **Dual Spline Trendlines**: Smooth bezier wave curves with dropdown selector (`Week ⌵`) and data marker.
- **Equalizer Stepping Bars**: Transaction velocity bars with threshold markers (`35%`, `65%`).
- **Transaction Queue Table**: Sleek dark table with status chips (`High`, `Normal`, `Critical`) and direct action buttons (`View`).
